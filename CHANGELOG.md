# Changelog

All notable changes to this repository. Versions follow semantic versioning: minor = new capability,
patch = fix.

## v1.0.1 — 2026-11-03

- README image source pages declare a registered page class (`diagram` for the pipeline, `showcase` for
  hero and social card) instead of the unregistered `figure`.
- Social card: the licence line has its own style class instead of reusing the pill class at another size.
- `docs/DEVELOPER.md` explains why the page-fill gate does not apply to the fixed-size image canvases.
- No change to the skills, the demo run or any README picture (all PNGs regenerate byte-identical).

## v1.0.0 — 2026-11-03

First public release.

- `reference-impl/skills/paper-distill/` and `reference-impl/skills/paper-story/`: the two skills with
  their scripts, schemas and method references, de-identified (declared edits E1–E4, R1–R3 in
  `docs/BUILD-SPEC.md` §9).
- `reference-impl/skills/paper-story/references/formal-deck.md`: new template-free formal deck
  reference (O1); `lab_deck.py` defaults to a generated blank 4:3 base.
- `reference-impl/tools/carriers/` (html-explainer, pptx-explainer) and `reference-impl/tools/page-fill-gate/`.
- `examples/fictional-paper/`: a generated fictional paper with deliberate evidence gaps;
  `examples/library/Placeholder2026_wax-delay-bridges/`: a full worked run on it.
- `verify/run_controls.py`: acceptance controls K1–K8, each two-sided with both asserted values printed.
- README images regenerated by `docs/assets/build_assets.py`.
